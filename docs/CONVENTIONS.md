# Конвенции кода, UI и проверки

Справочник для агентских сессий: как здесь принято писать и проверять, и почему.

## Деньги в UI

- **Ввод сумм — только текстовым полем** через `parseAmountExpr` (понимает
  запятую и точку, пробелы, ₽ и выражения «250000-1500»). Голый Mantine
  `NumberInput` для денег — ловушка: его разделитель по умолчанию — точка, и
  запятая копеек молча выбрасывается («138579,22» → 13 857 922). Там, где
  NumberInput всё же остался (правка снапшота в истории, суммы перетоков КАП),
  обязателен `decimalSeparator=","`.
- Форматирование: `fmtMoney` (округлённо), `fmtMoneyExact` (всегда копейки —
  страницы КАП и КС показывают точные суммы всюду), `fmtMoneyShort` (300K/1,2M —
  оси графиков), `fmtNumber`. Компонент `Money` c `exact` сам приглушает нули.
- Класс `.money` = tabular-nums + nowrap. Длинный текст с суммой внутри: класс
  вешать только на сумму, чтобы проза переносилась.
- После каждой арифметики с деньгами — `round2`; сравнения с допуском 0.005/1 ₽
  (копеечная пыль, см. DOMAIN.md).

## Таблицы-листы (месяц, год, доходы, КС)

- Компактные строки категорий: py 2, line-height 1.2, verticalAlign middle;
  «воздух» между категориями — отдельная невидимая строка-прокладка (SpacerRow,
  height 4, без границ), НЕ паддинги.
- Лосось заголовков = фон `var(--mantine-color-ink-1)` через
  `bottomLineBg(1, ...)` (градиент рисует нижнюю границу — обычный border у
  sticky-ячеек уезжает).
- **Автопрокрутки к текущей колонке НЕТ и не должно быть** — Виктория попросила
  убрать («задолбало мотать»): все листы открываются с начала. Не возвращать.
- Sticky-заголовки: у html/body и Card — `overflow: clip` (не `hidden`: hidden
  создаёт scroll-контейнер и убивает position:sticky). Класс `.group-scroll`
  включает липкий thead безусловно — не вешать его на таблицы, которым это не
  нужно (обычный `style={{overflowX:'auto'}}`).
- В таблице года у секции переводов `hideTotals` — суммы в шапке скрыты по
  просьбе Виктории.

## Формы и правки

- Server actions ('use server') + `revalidatePath('/', 'layout')`; API-роутов нет.
- Даты в формах — строки YYYY-MM-DD; `todayLocalISO()` на клиенте (пояс браузера),
  `todayISO()` на сервере.
- EditModal (TxList) — универсальная правка операции: категория (expense; включает
  row_type 'expense' И 'trip' — Поездки), счёт, дата, сумма-выражение, заметка,
  «скрыто из таблиц» и «размещение фонда» (transfer/saving с фондового счёта).
- Switch/Checkbox в async transition: значение `e.currentTarget.checked` захватывать
  ДО `startTransition` (currentTarget протухает).
- Бесконечные списки: курсор `{date,id}`, страницы по 50, IntersectionObserver +
  кнопка «Показать ещё» (IO в скрытом пейне заморожен — кнопка обязательна).

## Проверка работы

- `npx tsc --noEmit` — всегда перед отчётом.
- **Headless-тест server actions**: временный `.tmp-*.ts` в корне проекта
  (вне корня не резолвятся модули), запуск
  `DATABASE_URL="$(grep '^DATABASE_URL=' .env.local | cut -d= -f2- | tr -d '"')" npx tsx .tmp-test.ts`.
  Ошибка «Invariant: static generation store missing» от revalidatePath вне
  запроса — ожидаемая, запись в БД проходит; результат сверять через SQL.
  Тестовые строки создавать со маркером (`__тест...__`, note '[тест]') и всегда
  удалять; для КАП дополнительно сверять Σ леджера до/после.
- Локальная база — psql по DATABASE_URL из `.env.local`, читать и писать можно;
  прод — только SELECT, изменения только data-fix-миграциями (см. CLAUDE.md).
- Локальная база — старый снапшот прода: части данных может не хватать; guard'ы
  миграций обязаны быть no-op там, где предусловие не выполняется.

## Браузер-пейн (особенности окружения)

- Dev-сервер: `preview_start {name:"vika-pf"}`; порт 3000 иногда занят другим
  проектом Олега («Para») — попросить остановить.
- Логин: пароль вводит Олег; сессия — подписанная cookie (jose, AUTH_SECRET),
  90 дней. Пароли и токены не вводить ни в какие поля.
- Квирки: Drawer/Modal могут не отрисоваться на скриншоте скрытого пейна —
  проверять DOM через javascript_tool; скриншоты после JS-скролла бывают со
  смещённым paint'ом; IntersectionObserver заморожен; после перезапуска сервера
  cookie пейна слетает.
