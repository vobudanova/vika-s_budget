# Вика.Salmon — памятка для агентских сессий

Единственный пользователь приложения — Виктория. Оператор репозитория — Олег: он
пересылает её отзывы пачками, формулировки Виктории и есть требования. Репозиторий
**публичный** — никаких секретов, дампов данных и реальных сумм в коммитах и доках.

Перед работой с доменной логикой прочитай [docs/DOMAIN.md](docs/DOMAIN.md) (КАП, КС,
амортизация, балансы, знаки операций). Перед правкой UI и тестами —
[docs/CONVENTIONS.md](docs/CONVENTIONS.md). История импорта из Excel — docs/IMPORT.md.

## Рабочий цикл

1. Реализовать → проверить локально (tsc, браузер-пейн, headless-скрипты, psql).
2. Отчитаться и ждать. **Коммитить и пушить только по явной команде** («commit + push»).
3. После пуша: `gh run watch <id> --exit-status` в фоне; деплой на Vercel ~50–80 с;
   миграции применяет CI. Доложить, когда доехал (и проверить эффект миграций на проде).
4. Changelog для Виктории — только по запросу: по-русски, без жаргона, объясняя «что
   изменилось и как этим пользоваться» (см. тон прошлых в истории коммитов/чата).

## Жёсткие правила

- **Миграции**: рукописный SQL в `drizzle/NNNN_*.sql` обязан быть добавлен в
  `drizzle/meta/_journal.json`, иначе он молча не применится. Локально применяем
  `psql -f`, прод — CI при деплое.
- **Запись в прод — только data-fix-миграцией**: прямые INSERT/UPDATE в прод-базу
  запрещены (и блокируются). Миграция должна быть идемпотентной и с guard'ом,
  который делает её no-op на базах без нужного предусловия (локальный снапшот
  может отличаться от прода — пример: `0010_ks_himchistka_opening.sql`).
- Читать прод можно: `psql "$PROD_DATABASE_URL"` (строка в `.env.local`) — только SELECT.
- Секреты живут в `.env.local` (DATABASE_URL, PROD_DATABASE_URL, AUTH_PASSWORD,
  AUTH_SECRET) и в секретах GitHub/Vercel — их задаёт Олег сам (`gh secret set`).
  Значения не выводить в логи, доки и коммиты. Пароли в формы не вводить —
  в браузер-пейн логинится Олег.
- Дампы прод-данных не коммитить никогда (репо публичное; допустимы только
  шифрованные); `scripts/pull-prod-db.sh` в .gitignore — так и должно остаться.
- Фичи, удалённые по просьбе Виктории, не возвращать (список в CONVENTIONS.md).

## Быстрые факты

- Стек: Next.js 16 App Router (RSC + server actions, `force-dynamic`), Mantine 9,
  Drizzle + node-postgres; локально Homebrew Postgres, прод Neon; деплой Vercel.
- Прод: https://vika-sbudget.vercel.app. Git-интеграции Vercel НЕТ (владелец репо —
  vobudanova, у Олега нет админки): деплой делает только
  `.github/workflows/deploy.yml` (секрет VERCEL_TOKEN); Neon подключён
  Vercel-интеграцией (env DATABASE_URL).
- Проектный документ (модель данных, глоссарий, сквозные кейсы, открытые вопросы
  №4, 8, 9, 12, 17, 20–26) — приватный артефакт Олега «Вика.Финансы»:
  https://claude.ai/code/artifact/9062d207-0afd-4263-ab6b-d4818485645c
  (читается инструментом Artifact; ссылка сама по себе доступа не даёт).
- Dev-сервер: браузер-пейн `preview_start {name: "vika-pf"}` (`.claude/launch.json`),
  порт 3000 — его иногда занимает другой проект Олега.
- Тест server actions: `DATABASE_URL=... npx tsx .tmp-*.ts` из корня проекта; ошибка
  «Invariant: static generation store missing (revalidatePath)» вне запроса —
  ожидаемый шум, запись в БД при этом проходит. Тестовые строки всегда подчищать.
- Деньги: `numeric(14,2)` строками в Drizzle; `parseAmountExpr` понимает запятую,
  точку и выражения («250000-1500»); `round2` после каждой арифметики.
